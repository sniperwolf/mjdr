# Support

This document explains where and how to get help with MJDR.

## Using the issue tracker

Use the GitHub issue tracker for:

* [🐛 Bug Reports](https://github.com/sniperwolfl/mjdr/issues/new?template=bug_report.md)
* [✨ Feature Requests](https://github.com/sniperwolfl/mjdr/issues/new?template=feature_request.md)
* [📝 Documentation Issues](https://github.com/sniperwolfl/mjdr/issues/new?template=documentation.md)

## Before submitting an issue

- Check the documentation
- Search existing issues
- Try the latest version
- Try with debug mode enabled

## Getting help

1. First, check the [README.md](README.md) file
2. Search [existing issues](https://github.com/sniperwolfl/mjdr/issues)
3. Try running with --debug flag
4. Check logs in the container

## Support channels

* GitHub Issues: For bug reports and feature requests
* Email Support: [your-email] (for security issues)
* Discussions: For questions and community support
